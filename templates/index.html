Fake News Detection

Detect misleading news using Natural Language Processing and Machine Learning

💡 Tip: News models analyze journalistic style and reporting context. For best accuracy, test with full news paragraphs (20+ words) rather than brief casual statements.

About the Project

This Fake News Detection system uses Classical Natural Language Processing techniques to analyze news articles. TF-IDF converts text into numerical features and a Logistic Regression machine learning model predicts whether the news is REAL or FAKE.

The model achieved approximately 97.4% accuracy on the test dataset.
