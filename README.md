# Fake News Detection Using Classical NLP and Machine Learning

An academic Natural Language Processing (NLP) and Machine Learning project that classifies news articles as either **Fake** or **Real** using TF-IDF feature extraction and Logistic Regression.

## Project Structure
- `data/`: Dataset storage (CSV files)
- `models/`: Saved model weights and vectorizers (.pkl / .joblib)
- `src/`: Text preprocessing and model training scripts
- `templates/`: HTML templates for the Flask web application
- `static/`: CSS and JavaScript files for the web interface
- `app.py`: Flask application entry point
